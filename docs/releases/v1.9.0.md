# dev-api-proxy v1.9.0

Released November 26, 2026.

This release adds Moyuu support and automatic Xingchi history summaries.
It also restores an optional Xingchi client identifier override.

## Xingchi history and client compatibility

- Mode `2` summarizes older context at `88` model-turn items, before the 100-turn payload limit.
- Summary requests normally contain at most 64 model turns and keep tool calls with their results.
- Long histories use successive chunks. Each chunk includes the previous summary and remains below the turn threshold.
- Recent turns remain unchanged. Trusted instructions, tools, and output settings stay in the generation request.
- Summary text has a 256 KiB limit, separate from the 16 MiB response and stream limit.
- Streaming metadata no longer exhausts the summary-text budget.
- Empty, failed, incomplete, oversized, and turn-limit notice summaries produce an explicit error.
- Partial summaries never replace client history. The client's saved conversation remains unchanged.
- Up to 16 summaries are cached for one hour, isolated by credentials, model, endpoint, and prefix.
- Session rotation counts every upstream send, including summaries and retry attempts.
- OpenCode and normalized Codex session aliases share the correct upstream ID, with counters isolated by credentials.
- `XINGCHI_USER_AGENT` applies an optional `User-Agent` override to Xingchi native, converted Chat, and summary requests.
- An empty override preserves the caller's identifier. Other providers keep their original client headers.
- The updater validates both new runtime modules, `moyuu_proxy.py` and `xingchi_context.py`, before activation.

## Moyuu provider

- Moyuu has isolated `/moyuu/v1` and `/moyuu/v1beta` routes and its own `MOYUU_API_KEY` fallback.
- `MOYUU_UPSTREAM` defaults to `https://moyuu.cc`; an optional trailing `/v1` is normalized away.
- Moyuu runs New API and shares the FreeGG route allowlist: Responses, Chat, completions, Anthropic messages, embeddings, moderation, rerank, edits, images, audio, and the permitted Gemini actions.
- Moyuu Chat Completions are converted to Responses, matching the existing New API policy.
- Responses input-token counts, Anthropic token counts, Gemini `countTokens`, account administration, files, and WebSockets are not exposed.
- The Xingchi session filter does not apply to Moyuu.

## Model selection and isolation

- Picker IDs such as `moyuu/gpt-6.1-sol` route to Moyuu and remove the prefix before forwarding.
- Generated catalogs add `Moyuu · <model>` labels and a Moyuu compaction fingerprint prefix.
- Cross-provider choices use the selected provider's proxy-side key; unrelated client credentials are still removed.
- A missing `MOYUU_API_KEY` returns `provider_api_key_missing` without an upstream request.

## Consistency and diagnostics

- FreeGG and Moyuu share one New API path and method allowlist instead of separate copies.
- Relay log labels and catalog labels read from the single provider registry.
- Startup output, `/_health`, key redaction, launcher credential loading, and the updater's compile set include Moyuu.
- Both apps report the shared release version `1.9.0`.

## Upgrade

Wait for active requests to finish, update the checkout, and restart the proxy service.
Existing workers do not load the new modules until they restart.
Keep the existing `.env`; do not replace private keys with the example file.
Add `MOYUU_API_KEY` only when you want a proxy-side Moyuu fallback.

To enable automatic Xingchi summaries, set `XINGCHI_SESSION_FILTER_MODE=2`. The default remains `0`.
Each uncached chunk uses an additional model request, with a maximum of 4,096 output tokens.
Summaries can omit older details. Modes `0` and `1` and manual `/responses/compact` requests remain unchanged.

For `403 client_not_allowed`, configure the client identifier for your integration, then restart the proxy service:

```dotenv
XINGCHI_USER_AGENT=opencode/2.4.2
```

Use a versioned identifier for your installed client. Credentials, model access, and provider quotas still apply.

Regenerate a provider-labelled catalog to add Moyuu picker entries.
Four source models now produce 16 labelled choices and four hidden compatibility entries.
Existing model IDs remain valid. Restart ChatGPT desktop after changing its provider or catalog configuration.

Keys, private desktop configs, and user-specific model metadata are not included in this release.
Automated validation uses simulated upstreams and loopback fault servers, not paid model generation.

A separate live Xingchi check on November 26, 2026 completed with HTTP `200` using the versioned client identifier.
The 164-turn input was reduced to two summary chunks covering 128 old turns, plus 36 unchanged recent turns.
The completed response correctly returned a marker from the beginning of the original conversation.
This verifies that request path and account at that time; it does not guarantee other providers or accounts.
